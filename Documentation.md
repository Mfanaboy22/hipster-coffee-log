# Hipster Micro-Roastery Coffee Brew Log

A lightweight, responsive full-stack application built to track and log coffee brews for a boutique micro-roastery. This project satisfies all technical specifications including dynamic title counters, frontend/backend input validations, clean routing architectures, and strict environment configuration safety.

## Tech Stack Architecture
- **Frontend Layer:** HTML5, Bootstrap 5 CSS Framework, Vanilla JavaScript (Asynchronous Fetch Engine).
- **Backend API Engine:** Node.js, Express framework.
- **Data Persistence Layer:** Fast runtime memory schema with embedded input routing middleware.

## Setup and Installation Instructions
1. Clone or download this repository.
2. Open your terminal window and navigate to the backend directory:
   ```bash
   cd backend
   ```
3. Install necessary node module dependencies:
   ```bash
   npm install
   ```
4. Start up the backend API routing environment:
   ```bash
   npm start
   ```
5. Launch the frontend interface directly by opening `frontend/index.html` inside any modern browser window.
